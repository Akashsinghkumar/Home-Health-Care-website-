# Home-Health-Care-website-

Official website for **Shristy Home Health Care** — Trusted, compassionate, and verified home healthcare, elderly care, patient care, physiotherapy, and home nursing services in Patna.

## Features
- Responsive multi-page architecture
- Dedicated service pages (Elder Care, Baby Care, Patient Care, Home Nursing, Physiotherapy, Doctor Visit)
- Real caregiver gallery and verified reviews
- Direct WhatsApp & phone booking integration
- Modern styling with Bootstrap 5, Custom CSS, and GSAP animations
